# 0/1 Knapsack DP Visualization

## About
A Python project that solves the 0/1 Knapsack Problem using Dynamic Programming. It displays the DP table step-by-step using ASCII visualization and saves results in `result.txt`.

## Features
- Multiple test cases using `#Test`
- Step-by-step DP table visualization
- Maximum value calculation
- Results saved in `result.txt`

## How to Run
```bash
python knapsack.visualizer.py
```

## Complexity
- Time: O(nW)
- Space: O(nW)

## Files
- `knapsack.visualizer.py` — Python code
- `input.txt` — Test cases
- `result.txt` — Output
